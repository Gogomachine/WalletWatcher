# 🔥 Сброс базы данных

## Использование

### Способ 1: Запуск скрипта (рекомендуется)

```bash
python3 reset_database.py
```

Скрипт запросит подтверждение. Введите `ДА` для продолжения.

### Способ 2: Ручная очистка SQLite

```bash
# Остановите бота
# Удалите файл базы данных
rm data/wallet_watcher.db

# Запустите бота - БД создастся заново
python3 -m src.main
```

### Способ 3: Очистка PostgreSQL (если используется)

```sql
-- Подключитесь к БД и выполните:
DROP TABLE IF EXISTS tracked_addresses CASCADE;
DROP TABLE IF EXISTS address_groups CASCADE;
DROP TABLE IF EXISTS user_settings CASCADE;

-- Перезапустите бота для пересоздания таблиц
```

## ⚠️ ВНИМАНИЕ

После сброса базы данных будут удалены:
- ✖️ Все пользователи
- ✖️ Все отслеживаемые адреса
- ✖️ Все группы адресов
- ✖️ Все настройки
- ✖️ Все счетчики и история

Бот начнёт работу с чистого листа.

## После сброса

1. Перезапустите бота
2. Все пользователи должны будут заново:
   - Выполнить `/start`
   - Добавить адреса в отслеживание
   - Настроить группы и уведомления

## Решение проблем

Если после сброса возникают проблемы:

1. Убедитесь, что бот остановлен перед сбросом
2. Проверьте права доступа к директории `data/`
3. Проверьте логи бота после перезапуска

## Резервное копирование (опционально)

Перед сбросом можно сохранить копию:

```bash
# SQLite
cp data/wallet_watcher.db data/wallet_watcher.db.backup

# PostgreSQL
pg_dump $DATABASE_URL > backup.sql
```
