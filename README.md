# 🔍 WalletWatcher - Solana Address Monitoring Bot

Телеграм бот для отслеживания и мониторинга адресов в сети Solana. Получайте информацию о кошельках и уведомления о новых транзакциях в реальном времени.

## ✨ Возможности

- 📊 **Проверка адресов** - получение полной информации о любом Solana адресе:
  - Баланс в SOL
  - Возраст кошелька (время с первой транзакции)
  - Последняя транзакция с ссылкой на эксплорер
  - Определение биржевых адресов

- 📋 **Отслеживание адресов** - добавляйте адреса в список отслеживания:
  - Возможность задать никнейм для каждого адреса
  - Удобное управление списком отслеживаемых адресов

- 🔔 **Уведомления в реальном времени** - получайте мгновенные уведомления о:
  - Каждой новой транзакции на отслеживаемых адресах
  - С информацией о времени и ссылкой на эксплорер

- ⚙️ **Настройки** - управление уведомлениями и другими параметрами

## 📦 Установка

### Требования

- Python 3.9 или выше
- pip (менеджер пакетов Python)

### Шаг 1: Клонирование репозитория

```bash
git clone <repository_url>
cd WalletWatcher
```

### Шаг 2: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 3: Настройка переменных окружения

1. Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

2. Откройте `.env` и заполните необходимые параметры:

```env
# Получите токен от @BotFather в Telegram
TELEGRAM_BOT_TOKEN=your_bot_token_here

# Solana RPC URL (можно использовать стандартный или свой)
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com

# Путь к базе данных
DATABASE_PATH=./data/bot.db

# Интервал мониторинга в секундах (рекомендуется 10-30)
MONITOR_INTERVAL=10
```

### Шаг 4: Создание бота в Telegram

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env` файл

## 🚀 Запуск

Запустите бота командой:

```bash
python main.py
```

Бот начнет работу и выведет в консоль:

```
INFO - Initializing Solana client...
INFO - Initializing database...
INFO - Initializing address monitor...
INFO - Bot started!
```

## 📱 Использование

### Основные команды

- `/start` - начать работу с ботом
- `/help` - показать справку
- `/menu` - показать главное меню

### Проверка адреса

1. Нажмите "📊 Проверить адрес" в главном меню
2. Отправьте Solana адрес
3. Получите полную информацию:
   - Баланс
   - Возраст кошелька
   - Последняя транзакция
   - Является ли адрес биржевым

Пример адреса для проверки:
```
7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU
```

### Добавление адреса в отслеживание

1. Нажмите "➕ Добавить адрес"
2. Отправьте Solana адрес
3. При желании задайте никнейм (или пропустите)
4. Адрес добавлен! Теперь вы будете получать уведомления о каждой новой транзакции

### Управление адресами

1. Нажмите "📋 Мои адреса"
2. Выберите адрес из списка
3. Доступные действия:
   - 🔍 Проверить - получить актуальную информацию
   - 🗑️ Удалить - удалить из отслеживания

### Настройки

1. Нажмите "⚙️ Настройки"
2. Управляйте:
   - 🔔 Включение/выключение уведомлений
   - Просмотр количества отслеживаемых адресов

## 🏗️ Структура проекта

```
WalletWatcher/
├── main.py                 # Точка входа
├── requirements.txt        # Зависимости
├── .env                   # Конфигурация (не в git)
├── .env.example           # Пример конфигурации
├── data/                  # Данные (создается автоматически)
│   └── bot.db            # SQLite база данных
└── src/
    ├── __init__.py
    ├── bot/              # Телеграм бот
    │   ├── __init__.py
    │   ├── handlers.py   # Обработчики команд
    │   ├── keyboards.py  # Клавиатуры
    │   └── monitor.py    # Мониторинг адресов
    ├── solana/           # Работа с Solana
    │   ├── __init__.py
    │   └── client.py     # Клиент Solana RPC
    └── database/         # База данных
        ├── __init__.py
        └── db.py         # SQLite операции
```

## 🔧 Технологии

- **aiogram 3.4** - асинхронный фреймворк для Telegram Bot API
- **solana-py** - Python SDK для Solana blockchain
- **aiosqlite** - асинхронная работа с SQLite
- **python-dotenv** - управление переменными окружения
