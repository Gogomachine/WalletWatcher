# 🔍 WalletWatcher - Multi-Chain Address Monitoring Bot

Телеграм бот для отслеживания и мониторинга адресов в **множестве блокчейн сетей**. Получайте информацию о кошельках и уведомления о новых транзакциях в реальном времени.

**🆕 Поддержка множества сетей!** Solana, Ethereum, BSC, Polygon, Arbitrum, Optimism, Avalanche
**👥 Работа в группах!** Используйте бота в группах для совместного анализа адресов.

## ✨ Возможности

- 🌐 **Поддержка множества сетей** - работа с различными блокчейнами:
  - **Solana** (SOL)
  - **Ethereum** (ETH)
  - **Binance Smart Chain** (BNB)
  - **Polygon** (MATIC)
  - **Arbitrum, Optimism, Avalanche** и другие EVM-совместимые сети
  - **Автоматическое определение сети** по формату адреса

- 📊 **Проверка адресов** - получение полной информации о кошельках:
  - Баланс в нативном токене
  - Возраст кошелька (время с первой транзакции)
  - Последняя транзакция с ссылкой на эксплорер
  - Определение биржевых адресов
  - **Автоматическое распознавание адресов** в сообщениях
  - Правильные ссылки на эксплореры для каждой сети

- 📋 **Отслеживание адресов** - добавляйте адреса в список отслеживания:
  - Возможность задать никнейм для каждого адреса
  - Удобное управление списком отслеживаемых адресов
  - Команды `/track` и `/list` для быстрого доступа

- 🔔 **Уведомления в реальном времени** - получайте мгновенные уведомления о:
  - Каждой новой транзакции на отслеживаемых адресах
  - С информацией о времени и ссылкой на эксплорер
  - Уведомления приходят в личные сообщения (не спамят группу)

- 👥 **Работа в группах** - полная поддержка групповых чатов:
  - Автоматическое определение Solana адресов в сообщениях
  - Inline-кнопки для удобной навигации
  - Личные списки отслеживания для каждого пользователя
  - См. [GROUP_CHAT_GUIDE.md](GROUP_CHAT_GUIDE.md) для подробностей

- ⚙️ **Настройки** - управление уведомлениями и другими параметрами

## 📦 Установка

### Требования

- Python 3.9 или выше
- pip (менеджер пакетов Python)

### Шаг 1: Клонирование репозитория

```bash
git clone <repository_url>
cd WalletWatcher
```

### Шаг 2: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 3: Настройка переменных окружения

1. Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

2. Откройте `.env` и заполните необходимые параметры:

```env
# Получите токен от @BotFather в Telegram
TELEGRAM_BOT_TOKEN=your_bot_token_here

# Solana RPC URL (можно использовать стандартный или свой)
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com

# Путь к базе данных
DATABASE_PATH=./data/bot.db

# Интервал мониторинга в секундах (рекомендуется 10-30)
MONITOR_INTERVAL=10
```

### Шаг 4: Создание бота в Telegram

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env` файл

## 🚀 Запуск

Запустите бота командой:

```bash
python main.py
```

Бот начнет работу и выведет в консоль:

```
INFO - Initializing Solana client...
INFO - Initializing database...
INFO - Initializing address monitor...
INFO - Bot started!
```

## 📱 Использование

### Основные команды

**Базовые:**
- `/start` - начать работу с ботом
- `/help` - показать справку
- `/menu` - показать интерактивное меню

**Проверка адресов:**
- `/check <адрес>` - проверить конкретный адрес
- Просто отправьте адрес - бот автоматически распознает его

**Отслеживание:**
- `/track <адрес>` - добавить адрес в отслеживание
- `/list` - показать ваши отслеживаемые адреса
- `/settings` - настройки уведомлений

### Проверка адреса

Бот **автоматически определяет тип сети** по формату адреса!

**Способ 1: Автоматическое распознавание**
Просто отправьте адрес боту (или в группу):

**Solana адрес:**
```
7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU
```

**Ethereum адрес:**
```
0x742d35Cc6634C0532925a3b844Bc9e7595f0aA6F
```

**Способ 2: Команда**
```
/check 7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU
/check 0x742d35Cc6634C0532925a3b844Bc9e7595f0aA6F
```

**Способ 3: Через меню**
1. Отправьте `/menu`
2. Нажмите "📊 Проверить адрес"
3. Отправьте адрес

Вы получите полную информацию:
- 🌐 Определение сети (Solana, Ethereum, BSC и т.д.)
- 💰 Баланс в нативном токене (SOL, ETH, BNB, MATIC)
- 🗓️ Возраст кошелька
- 🔄 Последняя транзакция со ссылкой на эксплорер
- 🏦 Является ли адрес биржевым
- 🔗 Кликабельная ссылка на эксплорер сети

### Добавление адреса в отслеживание

**Способ 1: Команда (быстро)**
```
/track DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263
```

**Способ 2: Через меню (с никнеймом)**
1. Отправьте `/menu`
2. Нажмите "➕ Добавить адрес"
3. Отправьте адрес
4. При желании задайте никнейм (или пропустите)

После добавления вы будете получать уведомления о каждой новой транзакции!

### Управление адресами

Используйте `/list` или меню "📋 Мои адреса":
1. Нажмите на адрес из списка
2. Доступные действия:
   - 🔍 Проверить - получить актуальную информацию
   - 🗑️ Удалить - удалить из отслеживания

### Настройки

Отправьте `/settings` или "⚙️ Настройки":
- 🔔 Включение/выключение уведомлений
- 📊 Просмотр количества отслеживаемых адресов

### 👥 Использование в группах

Бот полностью поддерживает работу в групповых чатах!

**Добавьте бота в группу:**
1. Откройте группу → "Добавить участников"
2. Найдите вашего бота
3. Добавьте его

**В группе работают:**
- ✅ Автоматическое распознавание адресов
- ✅ Все команды (/check, /track, /list, /settings)
- ✅ Inline-кнопки для навигации
- 🔒 Личные списки отслеживания (у каждого свой)
- 📬 Уведомления приходят в ЛС (не спамят группу)

**Пример использования в группе:**
```
Пользователь: Смотрите какой кит!
Пользователь: 7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU

Бот: ⏳ Получаю информацию...
Бот: 📊 [Показывает полную информацию]
```
